# منهجية تقييم المنافسين بالنقاط والأوزان — أَثِيل

## 1) الغرض
تحويل مقارنة المنافسين من نقاش وصفي إلى قرار رقمي يساعد على:
- تحديد فجوات السوق السعودي
- ترتيب أولويات البناء
- تبرير خارطة المنتج والاستثمار

## 2) مقياس الدرجات
- 1 = ضعيف جدًا / غير ظاهر
- 2 = محدود
- 3 = متوسط
- 4 = قوي
- 5 = قوي جدًا / جوهري

## 3) الأوزان
تم توزيع الأوزان وفقًا لطبيعة أَثِيل كسوق سعودي ثقافي هجين (منصة + خدمات تشغيلية + حوكمة + ذكاء).

## 4) المعادلة الأساسية
النتيجة الموزونة للمنصة = مجموع (وزن الفئة × درجة الفئة)

WeightedScore = Σ (w × s)

## 5) التطبيع المقارن (اختياري)
Normalized100 = (WeightedScore / 5) × 100

## 6) معامل الثقة بالمعلومة (مهم)
لأن بعض البيانات مبنية على صفحات عامة لا عروض فنية/عقود فعلية:
- ثقة عالية = 1.0
- ثقة متوسطة = 0.8
- ثقة منخفضة = 0.6

ConfidenceAdjusted = WeightedScore × C

## 7) معامل الملاءمة للسعودية
SaudiFitScore = 0.35L + 0.25G + 0.20O + 0.20C

## 8) معادلة أولوية البناء داخل أَثِيل
BuildPriority = 0.40Gap + 0.30RevenuePotential + 0.20StrategicFit + 0.10Defensibility

## 9) معادلة صعوبة التقليد
Defensibility = 0.30DataMoat + 0.25WorkflowLockin + 0.20LocalPartnerships + 0.15IP + 0.10BrandTrust

## 10) ملاحظة تنفيذية
الأرقام في ملف CSV الحالي تقديرية أولية مبنية على معلومات عامة معلنة، ويجب تحديثها بعد عروض demos وRFPs واجتماعات فعلية.
