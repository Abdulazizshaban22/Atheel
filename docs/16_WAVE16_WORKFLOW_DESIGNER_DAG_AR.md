# Wave16 — مصمم مسارات عالمي: DAG Auto-Layout + Palette + Validation

هذه الحزمة ترفع مصمم المسارات إلى مستوى منصات الأتمتة العالمية عبر ثلاث ترقيات مباشرة:

## 1) DAG Auto-Layout باستخدام Dagre
تم اعتماد محرك layout خارجي لترتيب العقد تلقائيًا بناءً على علاقة المصدر والهدف (Directed Graph).
يتم ترتيب العقد عبر زر ترتيب DAG، وكذلك عند إعادة ضبط المخطط من القالب.

## 2) Palette لعقد جديدة
تم إضافة لوحة عقد يمكن سحبها وإسقاطها داخل اللوحة أو إضافتها بالنقر:

- Human Gate: بوابة قرار بشرية بمخرجين yes/no
- AI Action: إجراء ذكاء اصطناعي
- System Task: مهمة نظام

## 3) قواعد تحقق تمنع Graph غير صالح قبل الحفظ
تم تطبيق تحقق شامل قبل الحفظ ويظهر في لوحة الجانب:

- منع الدورات Cycle لضمان أن المسار DAG
- اشتراط وجود عقدة بداية واحدة على الأقل
- قيود Human Gate: مساران خروج فقط وعدم تكرار مسار yes/no
- تحذيرات للعقد غير المرتبطة أو الـ edges غير المكتملة
