# ملاحظات مصادر المقارنة التنافسية (مرجعية أولية)

هذه الملاحظات تُستخدم كمرجعية سريعة لتحديث مصفوفة المنافسين بأَثِيل وتثبيت فرضيات المقارنة قبل الديموهات والاجتماعات التجارية.

## منصات/جهات مرجعية
- Threads Culture (السعودية): مرجع خدمات ثقافية إبداعية ومشاريع تنفيذية في السوق السعودي
- Cultural Universe (وزارة الثقافة السعودية): مرجع وطني للتجربة الغامرة/الميتافيرس الثقافي
- Smartify: محتوى/تجارب/تطبيقات/تحليلات للمؤسسات الثقافية
- Veevart: تشغيل مؤسسات ثقافية ومتاحف (Museum OS)
- Dexibit: تحليلات وذكاء زوار للوجهات الثقافية
- STQRY: جولات ذاتية وتجارب رقمية للتراث والسياحة
- Arches: إدارة بيانات التراث الثقافي (Open Source)
- MuseumPlus (zetcom): إدارة مجموعات المتاحف
- Axiell: إدارة المجموعات والمتاحف

## استخدام داخل أَثِيل
- المقارنة ليست للتقليد، بل لتجميع أفضل الأنماط وبناء نموذج سعودي هجين (Platform + Studio + Heritage + AI + XR).
