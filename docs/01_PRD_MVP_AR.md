# PRD النسخة الأولى MVP

## هدف المنتج
منصة تشغيل ثقافي سعودي تجمع بين إدارة المشاريع والمحتوى وتجربة الزائر والتحليلات ومساعد AI.

## وحدات MVP
- إدارة المشاريع الثقافية
- مركز المحتوى الثقافي
- إدارة التجارب والمسارات
- لوحة مؤشرات تنفيذية
- مساعد محتوى ذكي (تلخيص/إعادة صياغة/ترجمة أولية)

## الفئات المستهدفة
- جهات ثقافية حكومية وشبه حكومية
- متاحف ومراكز ثقافية
- شركات تشغيل وتجارب ثقافية

## قصص مستخدم أساسية
1. إنشاء مشروع وربطه بجهة
2. إنشاء مادة محتوى وربطها بمشروع
3. إنشاء تجربة زائر وتحديد مدتها
4. مراجعة مؤشرات التنفيذ
5. استخدام AI للمساعدة في المحتوى

## مؤشرات نجاح MVP
- Pilot مدفوع
- أول تجربة زائر منشورة
- تقليل زمن إنتاج المحتوى
- استخدام أسبوعي نشط للفريق
