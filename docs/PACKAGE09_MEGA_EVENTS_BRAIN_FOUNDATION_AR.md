# الحزمة 09 — Atheel Mega Events Brain Foundation

هذه الحزمة تؤسس أول نسخة قطاعية لمجال الفعاليات الكبرى داخل أثيل.

## ما تمت إضافته
- Mega Events Brain module داخل API
- مسارات summary, agents, retrieve, evals, dashboard
- ربط أولي مع readiness وcrowd/operations logic
- صفحة واجهة `/domains/mega-events`
- agent catalog وmetadata schema أولية داخل knowledge-kernel

## الهدف
نقل أثيل من مجالين قطاعيين فقط إلى ثلاثة مجالات منفصلة، مع إبقاء الفعاليات الكبرى مرتبطة بالجاهزية والطوابير والمخاطر منذ البداية.
