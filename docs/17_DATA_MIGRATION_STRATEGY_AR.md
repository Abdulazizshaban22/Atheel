# استراتيجية ترحيل البيانات من الوضع الحالي (واتساب/إكسل/ملفات)

## مصادر شائعة
- ملفات Excel للمشاريع
- مستندات Word للمحتوى
- ملفات PDF للمواد التعريفية
- واتساب/إيميل للموافقات

## خطوات الترحيل
1. فهرسة البيانات
2. تنظيف وتوحيد المسميات
3. مواءمة الحقول مع نموذج المنصة
4. استيراد تجريبي
5. مراجعة جودة
6. استيراد نهائي
