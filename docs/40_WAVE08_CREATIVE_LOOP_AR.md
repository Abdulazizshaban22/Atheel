# Wave08 — حلقة الإبداع الثقافي قبل العرض الرسمي

## لماذا هذه الموجة
أكبر معاناة في القطاع الثقافي ليست التنفيذ فقط، بل مرحلة ما قبل العرض الرسمي:

1) البحث أولًا لمنع السرد الفضفاض
2) العصف الذهني الجماعي وتصفية الأفكار
3) الإلهام البصري والسردي الأقرب للثقافة المحلية
4) تحويل الفكرة إلى برنامج وتشغيل ومتابعة
5) محاكاة التجربة قبل التنفيذ وقياس جدواها
6) حفظ الأفكار كأرشيف حي يتوسع مع الزمن

## المكونات التي أضيفت

### 1) Inspiration Hub — الإلهام الثقافي
- مسارات API: /inspiration/sources و /inspiration/assets
- صفحة Web: /inspiration
- هدفها بناء بديل محلي قريب من Pinterest/Behance لكن بمصادر سعودية/رسمية/موثوقة.

### 2) Ideation Boards — العصف الذهني
- مسارات API: /ideation/boards + notes + voting
- صفحة Web: /ideation
- تدعم تدوين الملاحظات ثم Dot Voting لتصفية الأفكار.

### 3) Idea Vault — أرشيف الأفكار
- مسارات API: /vault/ideas + evidence + narrative
- صفحة Web: /vault
- حفظ كل أفكار الاستديو كأصول قابلة لإعادة الاستخدام والتطوير.

## إجبار البحث قبل السردية
- لا يسمح بتوليد سردية رسمية ما لم تكتمل حزمة الأدلة Evidence Pack
- الحد الأدنى الافتراضي: 3 مراجع
- شرط إضافي: مرجع رسمي سعودي أو UNESCO واحد على الأقل

## الربط المقترح مع الأتمتة
بعد اعتماد الفكرة (pitch_ready):
- إنشاء Program
- إنشاء Workflow Instance من كتالوج workflows
- توليد حزمة اعتماد + خطة تشغيل + خطة قياس
