# Sales and Demo Pack

## الرسالة الصحيحة
أثيل ليس مجرد prototype بصري، بل منصة تشغيل ثقافي متعددة الطبقات تم إغلاق مساراتها الأساسية على قاعدة بيانات فعلية، مع health وobservability وعقود تشغيل واضحة.

## سيناريو العرض المقترح
1. افتح Dashboard أو Home shell
2. انتقل إلى Review Center لإظهار approvals وattachments وaudit readiness
3. انتقل إلى Operations Center لإظهار health والqueues والجاهزية التشغيلية
4. انتقل إلى AI Center لإظهار memory وruntime وscorecards
5. اختم بعرض truth matrix وfinal readiness review لإثبات النضج التقني

## ما يجب عدم ادعائه
- لا تقل إن جميع الوحدات production complete إذا كانت truth matrix لا تزال تظهر scaffold_heavy
- لا تدّعِ جاهزية go-live قبل نجاح dress rehearsal
- لا تستخدم بيانات demo على أنها بيانات عميل حقيقي
