# تسلسلات تشغيل رئيسية (نصية)

## 1) إنشاء مشروع ثقافي
مدير البرنامج → منصة → Projects API → قاعدة البيانات → إشعار الفريق

## 2) إنتاج ونشر مادة محتوى
محرر → Content API → مراجعة → اعتماد → نشر داخل تجربة الزائر

## 3) تجربة زائر رقمية
مشغل التجربة ينشر المسار → الزائر يبدأ الرحلة → تتبع أحداث → Analytics API → لوحة المؤشرات

## 4) مساعد AI للمحتوى
محرر يرسل الطلب → AI API → مزود LLM (لاحقًا) → إرجاع مسودة → مراجعة بشرية
