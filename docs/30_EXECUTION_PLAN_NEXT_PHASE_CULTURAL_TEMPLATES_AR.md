# خطة المرحلة التالية لإضافة قوالب وأفكار ثقافية داخل أثيل
## المسار التنفيذي
### المرحلة 1
- بناء مكتبة قوالب معرفة
  - بطاقة فعالية
  - قصة موقع تراثي
  - وصف تجربة زائر
  - نص مرشد
  - لوحة تعريفية
- تخزينها في PromptTemplate + مكتبة محتوى أولي

### المرحلة 2
- ربط القوالب بمسارات Agent
  - تحليل الهدف
  - استرجاع المرجع
  - إنتاج المسودة
  - فحص الهوية الثقافية
  - اعتماد بشري

### المرحلة 3
- تقييم الجودة
  - دقة الحقائق
  - الالتزام بالنبرة
  - الوضوح
  - القابلية للنشر
  - المخاطر الثقافية/النظامية

### المرحلة 4
- مكتبة أفكار ثقافية قابلة للتوسع
  - فعاليات
  - تجارب زائر
  - أصول رقمية
  - قصص تفاعلية
  - مسارات تعليمية
  - حملات مجتمعية
