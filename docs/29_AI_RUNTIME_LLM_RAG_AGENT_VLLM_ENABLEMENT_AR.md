# تمكين طبقة الذكاء الاصطناعي في أثيل
## الهدف
إضافة طبقة تشغيل ذكاء اصطناعي داخل نفس المونوريبو تشمل
- مزودات نماذج لغوية
- قاعدة معرفة
- استرجاع معرفي
- مسارات وكلاء ذكية
- واجهات إدارة وتشغيل أولية

## ما تم إضافته في هذه الحزمة
### على مستوى الـ API
- توسيع وحدة ai لتدعم:
  - مزودات نماذج /api/ai/providers
  - تغذية قاعدة المعرفة /api/ai/knowledge/ingest
  - استرجاع RAG /api/ai/rag/query
  - تشغيل Agent /api/ai/agents/run
  - صحة الطبقة /api/ai/runtime/health
- دعم vLLM عبر واجهة OpenAI-compatible عند تفعيل المتغيرات

### على مستوى البيانات المؤقتة
- إضافة سجلات داخل DataStoreService لـ
  - مزودات الذكاء الاصطناعي
  - مستندات المعرفة
  - المقاطع
  - تشغيلات الوكلاء

### على مستوى Prisma
- إضافة نماذج جاهزة للترحيل:
  - AiProvider
  - KnowledgeDocument
  - KnowledgeChunk
  - AgentRun
  - PromptTemplate

### على مستوى المونوريبو
- إضافة حزمة @madar/ai-kernel
  - chunking
  - scoring بسيط
  - استرجاع
  - بناء Prompt لـ RAG
  - خطة Agent ثقافي

## ملاحظات مهمة
- التنفيذ الحالي يعمل بوضع محاكاة إذا لم يتم ربط vLLM
- الاستدعاء الفعلي لـ vLLM يتم فقط عند وجود VLLM_BASE_URL ومزود فعّال من نوع vllm_openai_compatible
- الكتابة إلى Prisma محمية بـ safe calls حتى لا يتعطل التشغيل قبل تنفيذ migrations

## أوامر العمل المقترحة بعد سحب الحزمة
1) توليد Prisma client وترحيل قاعدة البيانات
2) تفعيل Redis وطابور jobs لاحقًا لمهام Agent غير المتزامنة
3) ربط رفع الملفات الحقيقي (S3/MinIO) ثم ingestion تلقائي
4) إضافة تقييم جودة الإجابة ومراجعة بشرية داخل workflow الموافقات
