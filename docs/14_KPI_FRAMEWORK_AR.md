# إطار مؤشرات الأداء (تشغيلي + ثقافي)

## تشغيل
- نسبة التقدم بالمشاريع
- زمن دورة المحتوى (إنشاء → اعتماد)
- نسبة الالتزام بالمواعيد
- الحمل التشغيلي للفريق

## تجربة الزائر
- إكمال المسار
- متوسط زمن التفاعل
- تقييم المحطات
- معدل العودة

## الأثر الثقافي
- جودة الفهم بعد الزيارة (استبيان)
- تنوع الشرائح المستفيدة
- التفاعل مع القصص المحلية
- مشاركة المحتوى
