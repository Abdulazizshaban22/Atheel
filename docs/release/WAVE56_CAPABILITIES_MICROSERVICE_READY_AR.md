# Release Notes

## الإصدار
Wave56 Capability Packs

## الهدف
جعل المنصة قابلة للتركيب حسب المجال عبر تمكين وتعطيل حزم قدرات لكل جهة بدل تحويل المنتج إلى نسخة واحدة ضخمة.

## التغييرات
- إضافة كتالوج CapabilityPack
- ربط OrganizationCapability لتفعيل الحزم لكل جهة
- API لعرض الكتالوج وتمكين الحزم

## المخرجات
- تمهيد واضح لفصل النواة عن مجالات الأعمال
- تحسين قابلية التوسع لاحقًا لاستخراج خدمات حسب المجال
